# Password Strength Checker (PS No. 93)

## Problem Statement
A Python 3 program that checks a password against security rules and classifies it as Weak, Medium, or Strong, giving suggestions to improve it.

## Concepts Used
* **Strings:** Checking length, spaces, and formatting output.
* **Sets:** Checking for special characters (`@#$%&*!`).
* **Conditions:** Validating input and classifying scores (0-2 Weak, 3-4 Medium, 5 Strong).
* **Regex (`re`):** Pattern matching for uppercase, lowercase, and digits.

## How to Run
```bash
python password_checker.py
